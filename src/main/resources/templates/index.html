// Gestión de vuelos · Spring Boot + Thymeleaf

Sistema de Vuelos

Aeropuertos, líneas aéreas, aviones, programas, vuelos y escalas técnicas.

0 Aeropuertos Thymeleaf clásico: formulario con th:object
0 Aviones Relación @ManyToOne con ModeloAvion
0 Vuelos Instancias con fecha de un ProgramaVuelo
Mapa de la aplicación
Página Controller Cómo obtiene los datos
/aeropuertos AeropuertoVistaController Model + th:each, formulario POST /aeropuertos/guardar
/linea_aerea LineaAereaVistaController Model + th:each, formulario POST /linea_aerea/guardar
/modelosavion ModeloAvionVistaController Model + th:each, formulario POST /modeloavion/guardar
/aviones AvionVistaController Select de ModeloAvion + th:each
/programasvuelo ProgramaVueloVistaController 3 selects: LineaAerea + Aeropuerto origen + destino
/vuelos VueloVistaController 2 selects: Avion + ProgramaVuelo
/escalas-tecnicas EscalaTecnicaVistaController 2 selects: Vuelo + Aeropuerto + UNIQUE compuesto
/api/aeropuertos/listar AeropuertoController (REST) JSON: la misma tabla que ves en HTML, pero como API
